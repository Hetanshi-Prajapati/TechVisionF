## 🎯 Deploy in 20 Minutes!

### Step 1: Create Supabase DB (3 min)
```
1. supabase.com → Sign up (free, no credit card)
2. Create project "techvision"
3. Save connection string
```

### Step 2: Deploy on Render (10 min)
```
1. render.com → Create Web Service
2. Connect GitHub repo
3. Add Supabase variables
4. Deploy
```

### Step 3: Test (2 min)
```bash
curl -X POST https://YOUR-SERVICE.onrender.com/api/auth/signup \
  -H "Content-Type: application/json" \
  -d '{"fullName":"Test","username":"test","email":"test@test.com","password":"Test1234!","githubUsername":"test","primarySkill":"Java"}'
```
